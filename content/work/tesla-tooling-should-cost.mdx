## Context

New-product-introduction tooling is bought before the product it makes exists. There is no production history to price against, no second source already qualified, and a programme timeline that makes walking away expensive.

The work covered top-level assembly equipment, where a quote arrives as a single number for a bespoke item that only a handful of suppliers can build.

## Problem

Comparing bespoke tooling quotes against each other establishes which supplier is cheapest. It does not establish whether any of them is reasonable. With a small qualified supplier base and no comparable prior purchase, quotes can cluster well above cost without anything in the comparison revealing it.

The buyer needs an independent number — what the tool should cost to make — before the quote can be assessed at all.

## What I did

1. **Decomposed the tooling into cost inputs** — machining, material and labour — rather than treating the quote as a single price.
2. **Benchmarked each input independently** to build a should-cost position that did not depend on any supplier's own numbers.
3. **Assessed the quotes against the model**, which surfaced charges that were not visible in the quoted total.
