## What I built

I built this toolkit to turn three common supply-chain analyses into reusable browser
workflows. Load the CSV you already have, map the columns where needed, and get results you
can filter, sort and export.

## Three workflows

### Inventory Planner

Calculates days of cover, lead-time demand, reorder points, inventory position and
MOQ-rounded order recommendations.

### Freight Exceptions

Benchmarks cost per mile against the lane average, then flags high-cost or late shipments. A
shipment meeting both conditions is marked Critical.

### Supplier Scorecard

Scores suppliers across delivery, quality, cost and service, with weights you can change to
match what a category actually rewards. Suppliers missing data on a dimension are marked as
incomplete rather than given a score the data does not support.

## How it works

Upload CSV → map columns → analyze → filter/sort → export results

You do not need exact header names. Common variants of each field are matched automatically,
so a file that calls a column `Stock On Hand`, `on_hand` or `Quantity On Hand` resolves the
same way. If a required field is left unresolved, the mapping interface lets you pick the right
column before the analysis runs. Columns the workflow does not use are ignored.

## Build approach

- **AI-assisted build.** I used Claude, alongside Codex, as development copilots for
  implementation, iteration and QA. The supply-chain rules and expected outputs were defined
  explicitly and tested against known results.
- **Deterministic analysis.** Inventory, freight and supplier calculations are defined in code
  rather than generated by a language model.
- **Browser-side processing.** Uploaded CSV data is parsed and analyzed in the browser. No
  database is required and session data is not persisted.
- **Optional AI Brief.** When requested, the AI layer summarizes already-calculated structured
  results. Raw uploaded CSV files are not sent to the AI endpoint.
