# Esmail Arshad — Supply Chain Portfolio

A professional portfolio covering supply chain planning, sourcing, logistics, operations and analytics through selected projects, career experience and case studies.

[View the live portfolio](https://esmail-arshad-portfolio.vercel.app/)

## Portfolio

- **Projects:** Inventory planning and freight-cost analysis with verified operational findings.
- **Career:** Seven roles spanning manufacturing, technology, logistics and supply-chain operations.
- **Case Studies:** Detailed decision-focused examples from career experience and client work.

The Excel workbooks in `content/artifacts/` are intentionally public, sanitized portfolio versions included as supporting proof of work for the related client case studies. Client identities, confidential details and sensitive commercial information have been removed or anonymized; original and unsanitized client files are not shared.

## Stack

- Astro
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
npm run build
npm run preview
```

The production build is generated in `dist/`.
